# Keyboard Shortcuts & Support

## Overview

DragBizz is keyboard-friendly: **Alt + letter** jumps between pages, common actions have hotkeys on every list page, and **Shift + ?** opens the Support Center — which has a Suggestions box, Help Center (FAQs and quick-start), and the full Shortcuts reference.

## Navigation shortcuts (global)

| Keys | Goes to |
|---|---|
| Alt+H | Dashboard |
| Alt+I / Alt+C / Alt+P | Invoices / Customers / Products |
| Alt+S / Alt+U / Alt+B | Stock / Suppliers / Bills |
| Alt+E / Alt+Y / Alt+O | Expenses / Payments / Sales Orders |
| Alt+Shift+O | Purchase Orders |
| Alt+A | Analytics |
| Alt+F / Alt+M / Alt+L | Staff / Subscription / Plan Limits |
| Alt+G / Alt+Q | Settings / Support |
| Alt+V | Voice assistant |
| Alt+\ | Toggle sidebar |
| Shift+? | Support Center |

## Action shortcuts (on list/detail pages)

| Keys | Action |
|---|---|
| Shift+N | Create new (invoice, expense, etc.) |
| / or Ctrl+K | Focus search |
| Ctrl+S / F1 | Save |
| Ctrl+P / F2 | Print |
| Ctrl+D | Download |
| Ctrl+E | Edit |
| Delete / Ctrl+Delete | Delete |
| Alt+1 / Alt+2 | Table / Card view |
| Esc | Close drawer/modal |

**POS extras:** Ctrl+Enter checkout, Ctrl+Delete clear cart, / focus product search.

## Support Center (`/dashboard/support`)

- **Suggestions** — submit ideas with Title, Category (Feature, UI/UX, Report, Theme, Integration, Other), and Description; browse and **upvote** others' suggestions. (Owner accounts; staff see Help and Shortcuts only.)
- **Help Center** — FAQs, a quick-start checklist, and links to POS, Inventory, Analytics, and Settings guides.
- **Shortcuts** — the searchable in-app list of all keyboard shortcuts.

## Examples

- "Jaldi naya invoice" → Alt+I then Shift+N (or Alt+H → New Invoice quick action).
- "Feature request dena hai" → Shift+? → Suggestions → submit; others can upvote it.
- "Shortcut yaad nahi" → Shift+? → Shortcuts tab.

## Errors

- "Title and description are required" — suggestion form incomplete.
- Shortcuts that open plan-gated pages (e.g., Analytics) still respect plan/permission gates.

## FAQ

**Q: Shortcuts kaam nahi kar rahe?** 
Make sure focus isn't inside a text field for single-key shortcuts (like `/`), and that your role has access to the target page.

**Q: Kya suggestions par team reply karti hai?** 
Suggestions land with the DragBizz team; statuses/upvotes are visible in the same tab.
