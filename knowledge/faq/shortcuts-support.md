# Keyboard Shortcuts & Support

## Overview

DragBizz is keyboard-friendly. **Alt + letter** jumps between pages from almost anywhere on the dashboard. List/detail pages share common action hotkeys. **Shift + ?** opens Support Center → **Shortcuts** tab (full searchable list). On Mac, **Ctrl** acts like **Cmd** and **Alt** like **Option** for these app shortcuts.

## Action shortcuts (list & form pages)

| Keys | Action |
|---|---|
| Shift+N | Create new (invoice, expense, customer, etc. — page-dependent) |
| / | Focus search input |
| Ctrl+K | Toggle / focus search |
| Ctrl+S or F1 | Save current form |
| Ctrl+P or F2 | Print |
| Ctrl+D | Download PDF / report |
| Ctrl+E | Edit selection |
| Delete or Ctrl+Delete | Delete item |
| Alt+1 | Table view |
| Alt+2 | Card view |
| Esc | Close drawer / modal (or collapse chat fullscreen) |
| Ctrl+Esc | Navigate back |
| Shift+Backspace | Global navigate back |

## POS shortcuts (on `/dashboard/pos`)

| Keys | Action |
|---|---|
| / or Ctrl+K | Focus product search |
| Ctrl+Enter | Checkout / charge |
| Ctrl+Delete | Clear cart |
| Ctrl+Shift+N | New sale (after success) |

## Chat / voice assistant (Alt+V)

| Keys / input | Action |
|---|---|
| Alt+V | Open / close chat |
| Esc | Collapse fullscreen, then close |
| Enter | Send message |
| Shift+Enter | New line in composer |
| / in chat box | Slash command menu (↑↓ + Enter to pick) |

Slash examples: `/sales`, `/dues`, `/stock`, `/create-customer`, `/find-customer`, `/invoice`, `/payments`, `/gst`, `/help`, and more.

## Where to see them in-app

1. Press **Shift+?** → Support Center → **Shortcuts** tab.
2. Sidebar hover / collapsed tooltips also show **⌥** / Alt hints for many routes.

## Examples

- New invoice fast: **Alt+I** then **Shift+N**.
- Open chat: **Alt+V**, type `/create-customer`.
- Forgot a key: **Shift+?** → Shortcuts.

## FAQ

**Q: Give me all shortcut keys of DragBizz dashboard**  
See the tables above (navigation, actions, POS, chat). Full list also lives under Support → Shortcuts.

**Q: Shortcuts not working?**  
Single-key shortcuts like `/` need focus outside a text field. Plan/permission gates still apply (e.g. Analytics). On Mac use Option/Cmd as listed.

**Q: Alt+B — Bills or Cashbook?**  
Global hotkey **Alt+B** opens **Bills**. Cashbook is available from the sidebar Sales menu (no unique global Alt key today).
