# Appearance — Light/Dark Mode & Accent Color Themes

## Overview

Appearance lives at **Settings → Appearance** (`/dashboard/settings?tab=appearance`). It has two independent controls:

1. **Interface mode** — Light or Dark (brightness of the UI).
2. **Accent color themes** — which brand/accent color the app uses (buttons, highlights, active states).

These are not the same thing. Asking "kitne color themes hain" / "how many theme types" means the **accent color themes**, not Light vs Dark.

Staff and owners both can change Appearance. Changes apply instantly on this device.

## Interface mode (2 options)

| Mode | When to use |
|------|-------------|
| **Light** | Bright environments |
| **Dark** | Low light / easier on the eyes |

There is **no** "follow system" / auto mode. Only Light and Dark.

## Workflow

1. Open **Settings → Appearance**.
2. Pick **Light** or **Dark** under Interface Mode.
3. Open an accent category tab (**Warm / Cool / Green / Vibrant / Neutral**) and click a color theme card. A live preview shows primary/secondary buttons.
4. Optional: **Reset to Defaults** — sets accent theme back to **Default** and mode back to **Light**.

## Business rules

- Interface mode and accent theme are independent — e.g. Dark + Rose, or Light + Midnight, both work.
- Appearance is saved **per device/browser**, not on the cloud account. Signing in on another computer starts from defaults until you pick again.
- There is no custom hex color picker — only the 22 built-in accent themes.
- Language, profile, and password settings are separate tabs (see account settings docs).

## FAQ

**Q: How many color theme types are there?**  
**5 types (categories):** Warm, Cool, Green, Vibrant, Neutral. Together they contain **22** accent color themes.

**Q: Is Dark/Light a color theme?**  
No. Light and Dark are **interface modes** (brightness). Color themes are the accent palettes (Default, Ocean, Violet, Emerald, etc.).

**Q: What is the default appearance?**  
Accent theme **Default** (Warm category) and **Light** mode. Reset to Defaults restores both.

**Q: Why did my theme change on another laptop?**  
Appearance is stored per device, not synced to your account.

**Q: Can I set a custom brand color?**  
No — choose from the 22 built-in accent themes only.
